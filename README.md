# 简易量房工具

一个"数值驱动"的量房绘图网页：**画布上不存在自由落点，每一个点的位置都由方向和长度算出来。**

适合现场量房、装修放线、面积核对。第一版只做网页，后续再考虑微信小程序。

## 核心理念

1. **禁止任意选点**。新点只有两种来源：选中已有的端点，或在已有墙上按数值取点（例如"距起点 1500mm"）。
2. **不自动改数字**。闭合差多少就报多少，系统绝不偷偷拉长某段墙把图形"配平"。
3. **一切可追溯**。每个点都记着它从哪来：哪个点、什么方向、多少毫米。
4. **毫米整数**。坐标全程整数毫米，屏幕像素只负责显示，避免浮点误差累积。

## 当前进度

已完成（可运行、有测试覆盖）：

- 方向指盘 + 数字键盘的自绘录入界面，全程不用系统键盘
- 按"方向 + 长度"连续落线，回到既有端点自动连接、不产生重复点
- 辅助定位线：参与定位，不算墙体、不参与面积
- 沿已有墙按数值取点：会在墙上插入真实端点并把原墙拆成两段，
  内墙从外墙中间长出来时，房间区域才能圈得闭合
- 闭合差提示：只报告"东西/南北方向差多少"，不修改任何输入值
- 墙厚偏移与 L 形转角自动延伸相交；内墙默认零厚度不偏移，实测后再设厚度生成第二条线
- 墙面轮廓、端点、长度标注的 SVG 画布，支持鼠标与触屏平移缩放
- 选中墙体后：改长度（后续墙跟随平移）、切换内外墙、改墙厚、翻转偏移侧、删除
- 改动牵连出的非正交墙会被标记为**冲突墙**（红色虚线），交给用户修正
- 撤销 / 重做（命令式快照栈）
- 浏览器本地自动保存（IndexedDB）+ 工程列表 + 工程文件 `.json` 导入导出
- 门窗洞口录入：窗/门类型、宽、高、离地高度、距墙左端距离，全部用自绘数字键盘填值
- 立面上也能手画：用方向＋长度（上／右／下／左）画矩形，四笔闭合后一键标记为窗或门
- 单墙立面视图：从室内侧观察，左右端按"站在室内面朝墙时的左手边"对齐
- 洞口在平面图上自动断墙并画出符号：窗为三线，门为门扇线加开启弧线
- 洞口越界校验（超出墙长或墙高时给出中文原因，不写入数据）
- 墙面毛面积与扣除洞口后的净面积
- 手动圈定房间区域、房间名与备注、净面积实时计算、面积清单 CSV 导出
- 整体四向立面：按观察者方位投影，只取朝外的外墙，左右按现场视线方向排列
- 等轴测线框：外墙体量 + 洞口轮廓，不做消隐
- DXF 导出：平面图 + 东西南北四张立面 + 等轴测，各占一个图纸空间页
- 图纸空间分页带 A3 横放图框与标题栏，比例从 1:20 到 1:500 自动选档
- 图层分色：`WALL` / `OPENING` / `ROOM` / `FRAME` / `TITLE` / `AXON`，图面文字为中文
- 独立校验脚本 `tools/verify_dxf.py`：用 ezdxf 回读，核对版本、单位、图纸页与审计结果
- 工程设置：统一层高与外墙厚度可改，支持一键应用到所有外墙；单面墙可覆盖墙高
- 视角规则：平面图默认锁定为正俯视（可解锁）；三维视图水平方向锁在东西南北、只调俯仰；
  等轴测是独立的固定轴测视图
- 方位指示器：东西南北上下六个方向用同一套投影算出，跟着视角一起转
- 视角吸附：接近正俯视、平视或轴测角度时自动对齐
- 两套布局：手机端底部常驻操作坞 + 上滑浮层；桌面端右侧常驻面板，互不迁就
- 四向立面始终输出东南西北四张图，某一侧没有外墙也留空框；
  尺寸数字放大并坐在断开的尺寸线中间
- 方位指示器只画东（红）、南（绿）、上（蓝）三根带箭头的轴；正俯视时"上"正对观察者，
  自动隐藏，不会挤在圆心
- 平面锁定改成画布右下角的锁形图标；上、下方向键放在十字下方，只占高度不占宽度
- 桌面端画布与右侧面板之间可拖动分栏；支持物理键盘：W/A/S/D 对应屏幕的北/西/南/东，
  Q/Z 对应上/下，数字直接输入，回车落线，退格删除，Ctrl+Z 撤销
- 画布右下角锁形按钮：点锁定时先回到离当前最近的标准正视图（平面图／东西向／南北向），
  平面图一律回正到北朝上
- 适配视图旁是标准视图切换按钮，按平面图 → 东西向 → 南北向循环
- 缩放范围放到 1mm 能占几十像素，长度数字按世界尺寸绘制，缩放时与图纸等比放大
- 线条按方向分色：东西红、南北绿、上下蓝；长度数字坐在断开的线中间
- 手机端点“区域／墙体／洞口”会把键盘区整块换成对应卡片，不再盖住画布
- 打开网页自动载入最近编辑的工程，本地存储不可用时自动降级为不保存
- 几何核心单元测试

## 技术栈

React 19 + TypeScript + Vite，zustand 管理状态，SVG 渲染画布。几何计算全部自研，不依赖几何库。

## 本地运行

```bash
npm install
npm run dev      # 开发服务
npm run test     # 单元测试
npm run build    # 生产构建，产物在 dist/
python tools/verify_dxf.py .validate/sample.dxf   # 独立校验导出的 DXF
```

导出的图纸用真实 DXF 解析库回读验证，当前结果：**审计 0 错误、0 修复**，图纸页
`Model / 平面图 / 东立面 / 南立面 / 西立面 / 北立面 / 等轴测` 各自包含对应图元。


## 坐标与方向约定

- 内部坐标：**北为正 Y，东为正 X**，单位毫米，整数。
- 渲染时再翻转 Y，屏幕上北在上、东在右。
- 墙厚偏移方向记在墙上（左/右，可一键翻转），沿"起点指向终点"的方向判断左右。
- 单墙立面的水平轴按"站在室内侧、面朝该墙时的左手边"对齐，保证现场对照不左右颠倒。

## 单位与默认值

层高 2800mm、外墙厚 240mm、内墙厚 100mm、窗 1500×1500 离地 900mm、门 900×2100 离地 0，均可在工程内修改。
